# 🤖 Telegram Video Downloader Bot

A Telegram bot built in C that downloads videos from popular platforms.

## ✨ Features

- 🎥 Download videos from YouTube
- 📸 Download videos from Instagram
- 🎵 Download videos from TikTok
- 💬 Simple command-based interface
- ⚡ Fast and lightweight

## 🛠️ Commands

| Command | Description |
|---------|-------------|
| `/start` | Start the bot |
| `/help` | Show help menu |
| Send a link | Bot detects the platform and downloads |

## 📋 Requirements

- Telegram Bot Token (from [@BotFather](https://t.me/BotFather))
- libcurl
- libjson-c
- yt-dlp

## 🚀 Installation

```bash
sudo apt install libcurl4-openssl-dev libjson-c-dev yt-dlp
